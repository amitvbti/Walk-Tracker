# Walk Tracker Final

Offline round-only walking tracker.

- Morning and Evening tracked separately.
- Any integer 0–199 rounds.
- Calendar colors are independent for Morning and Evening: 0–10, 11–20, 21–199.
- No step counts or step calculations.
- Calendar cells show date, Morning rounds, Evening rounds, and EDIT.
- Data is stored locally on the phone.
- Every save updates an automatic private local backup.
- Android 10+ also keeps `Downloads/WalkTracker/WalkTracker_AutoBackup.json`.
- Manual Backup/Restore uses the Android file picker.
- Restore validates the backup before replacing local data.
- No login, registration, server, cloud, or internet dependency.
