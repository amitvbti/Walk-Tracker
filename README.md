# Walk Tracker

A simple offline Android walking tracker.

- No login or registration
- 250 steps = 1 round
- Morning and Evening tracked separately
- 10 and 20 round quick buttons
- Calendar history with color levels
- Local data storage
- Backup/Restore as JSON
- No server required

## Beginner build route

The project includes a GitHub Actions workflow. Upload this project to a GitHub repository, then open **Actions → Build APK → Run workflow**. When the workflow finishes, download the **WalkTracker-debug-apk** artifact and install the APK on the Android phone.
